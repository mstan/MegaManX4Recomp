MegaManX4Recomp - Mega Man X4, recompiled
==========================================
1.0.11-4p-spike.1 - Four Player Co-op Preview (Windows x64)

WHAT YOU NEED
  Your own original, unmodified Mega Man X4 (USA, SLUS-00561) disc image.
  A .cue + .bin pair is preferred; a bare .bin also works.
  Do not convert it to a 2048-byte cooked
  .iso: that discards the XA sectors used for the game's FMV and audio.

  Only the verified original disc listed in DISC.md is accepted, even with
  every mod disabled. Apply undubs, translations and other changes through
  Mods over the original disc. Modified disc images are unsupported.

  A PlayStation BIOS is not required. This package bundles the MIT-licensed
  OpenBIOS from PCSX-Redux (bios/openbios.bin, notice in bios/OpenBIOS.LICENSE).
  You may optionally select your own legally obtained SCPH1001.BIN instead.

FIRST RUN
  1. Run MegaManX4Recomp.exe on Windows.
  2. Set the Disc row to your Mega Man X4 image.
  3. Widescreen / Adaptive and Resident Asset Loading default on.
     This preview uses native internal resolution and the render worker. Interpolation is unavailable;
     generic CD speed and host timing controls are retired. Optional Damage
     Multiplier defaults to normal 1x damage.
  4. Press Play. Your choices are remembered for next time.

FOUR PLAYER CO-OP PREVIEW
  Enable Mods -> Four Player Co-op. In Controls, assign every seat to a
  controller or keyboard. Your personal bindings are not included in this ZIP.
  Default roster: X / Zero / Ultimate Armor X / Black Zero. Forms must be
  unique. Set Player 4 to None for three players. Only complete forms are
  available. This mod disables the two-player and separate armor-code mods.

  Local play always uses independent split cameras: P1 top left, P2 top
  right, P3 bottom left and P4 bottom right. With three players, P3 uses
  one centered 4:3 pane below P1/P2, with black pillars on either side.
  Local unified four-player play is deferred.
  Online camera choices are on Netplay; individual views are the default.
  Every peer must use this exact preview build and the same roster.

  Each player has their own X/Zero pause screen, HUD and spawn animation.
  Co-op Free Cutscenes is a separate default-off experiment. Doors and room
  transfers retain the normal partner gathering and protection rules.

  Four-player save states and rewind are unavailable. Native memory-card
  saves retain mod isolation. Diagnostic recording is optional and off.
  Complete campaign, vehicles, all bosses/scripts/weapons, Internet/ICE,
  spectators and cross-platform four-player play are not yet qualified.
  Heavy gameplay performance and some legacy two-player menu/pause cases
  remain under investigation. See RELEASE_NOTES.md and
  docs/EXPERIMENTAL_FOUR_PLAYER.md for scope and evidence.

TWO-PLAYER CO-OP (SEPARATE MOD)
  In Mods, enable X + Zero Co-op for local play. OpenGL is required, and
  enabling co-op takes effect on a fresh boot. The X + Zero Co-op netplay
  profile enables it for both peers; use the same release on both computers.
  Unified is the default camera mode. The host may choose Split
  for independent online views. Local co-op display also offers Side by side 8:3
  with two 4:3 cameras in one window. Requires a fresh boot.

  Select Netplay in the launcher to host or join a two-player room using the
  X + Zero Co-op profile. For local play, Controls offers Player 1 and Player 2
  assignments; choose a different physical controller for each player, even
  when both controllers are the same model. Keyboard controls can also be
  assigned separately. Pause uses Start/Options or the assigned keyboard key.

  Shared-view lifebars default to Stacked; Mods -> X + Zero Co-op -> HUD layout
  also offers Side by side. Split shows each local player
  at the original HUD position. A dead player waits for the team's retry;
  native scene changes carry living partners along using teleport animations.
  Split health pickups refill their collector without freezing the partner;
  Unified keeps the original shared refill pause.

  Ultimate Armor X Code and Black Zero are optional, separate Mods toggles.
  Both can be enabled together for local play. The X code makes a capsule
  grant Ultimate Armor; it does not grant armor immediately. For online
  co-op, the host selects these two options under X + Zero Co-op.

  Player 1 owns the campaign and permanent upgrades. Boss clears are shared;
  the lives counter shows team retries. Either living player can use Select in
  the pause menu to Quit, or select Escape in a cleared stage.

  Offline TWO-PLAYER co-op supports save states and rewind. F7 opens save states:
  Square saves, Cross loads, and Circle goes back, using your configured
  controller/keyboard bindings. F8 opens rewind when Rewind is enabled.
  These features are unavailable during a netplay match.

  Diagnostic recording is optional and defaults off. For local play, enable
  Mods -> Playtest Diagnostics -> Input Display and Recording. For netplay,
  the host enables X + Zero Co-op -> Netplay diagnostic recording for both
  peers before starting a match. Existing explicit preferences are preserved.
  It shows both players' accepted buttons and REC while recording.
  It records each run under saves/diagnostics, including starting memory
  cards and mod choices. Keep the session folder for reproducing a report;
  offline input replay needs the matching build and settings.
  Recordings always live in saves/diagnostics beside the executable, or beside
  the .AppImage file. Memory-card directory changes do not move recordings.
  diagnostics-location.txt in that same application folder gives the exact path.
  Quit normally, then zip the entire named session folder with your bug report.
  A save-state load or rewind starts a new session with baseline.pst. Include
  that file along with the inputs, settings and starting memory cards.
  Recordings include starting game saves. Netplay traces are for inspection;
  full netplay replay is not supported.

  Startup failures are recorded automatically, even before gameplay starts.
  If sign-in fails or a peer stays on a white screen/in the lobby, send the
  newest startup-*.log from each peer's saves/diagnostics folder beside the
  executable or AppImage. startup-log-location.txt gives the latest path.

  This release has limited stage coverage. Split may still run below full
  speed, and retries, vehicle stages, and chained scenes need more playtesting.
  Report the release version, stage/area, camera mode, and which player led.

OPTIONAL LANGUAGES
  In Mods -> Text Translation, choose Spanish or Brazilian Portuguese.
  Dialogue uses the game's original font. Translations are drafts awaiting
  native-speaker review; voices and artwork are not translated.

  For Japanese media, supply your own Rockman X4 (Japan, SLPS-00902) disc
  under Mods -> Japanese Media. Choose Japanese FMVs, Japanese voices
  and the Rockman X4 title screen independently. Japanese FMVs offers
  No subtitles, English or Spanish; only the selected source is needed.
  Fan-subtitled movies are imported locally with the included
  tools/import_fmv_subtitles.py. No Japanese disc or movie pack is bundled.
  See docs/LOCALIZATION.md and docs/FMV_SUBTITLES.md for setup and credits.

WHERE THINGS LIVE
  saves/     memory cards
  cache/     native code cache, created locally for eligible uncovered code
  mods/      bundled and user-installed mod packages
  input.ini  controller mapping (yours after first launch)

  On Linux the AppImage seeds these into ~/.local/share/MegaManX4Recomp.
  Override that location with MMX4_RECOMP_DATA_DIR.

PRIVACY NOTE
  overlay_captures.json and cache shards produced while playing contain code
  converted from your disc. Do not redistribute your own capture data.

PUBLIC BETA
  Reported co-op regressions and a two-boss native memory-card save/cold-load
  loop have passed bounded checks. Complete campaign coverage is still being
  expanded. Please report an unknown-dispatch halt with where it occurred.
