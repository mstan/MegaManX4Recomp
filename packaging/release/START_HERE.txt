MegaManX4Recomp - Mega Man X4, recompiled
==========================================

WHAT YOU NEED
  Your own Mega Man X4 (USA, SLUS-00561) disc image. A .cue + .bin pair is
  preferred; a bare .bin also works. Do not convert it to a 2048-byte cooked
  .iso: that discards the XA sectors used for the game's FMV and audio.

  A PlayStation BIOS is not required. This package bundles the MIT-licensed
  OpenBIOS from PCSX-Redux (bios/openbios.bin, notice in bios/OpenBIOS.LICENSE).
  You may optionally select your own legally obtained SCPH1001.BIN instead.

FIRST RUN
  1. Run MegaManX4Recomp.exe on Windows, or the AppImage on Linux.
  2. Set the Disc row to your Mega Man X4 image.
  3. Custom Renderer / Adaptive and Resident Asset Loading default on.
     Internal resolution defaults to 1080p. Interpolation is unavailable;
     generic CD speed and host timing controls are retired. Optional Damage
     Multiplier defaults to normal 1x damage.
  4. Press Launch. Your choices are remembered for next time.

CO-OP PLAYTEST
  In Mods, enable X + Zero Co-op for local play. OpenGL is required, and
  enabling co-op takes effect on a fresh boot. The X + Zero Co-op netplay
  profile enables it for both peers; use the same release on both computers.
  Unified is the default camera mode. The host may choose Split (Experimental)
  for independent online views; offline play uses Unified.

  Shared-view lifebars are stacked vertically. Split shows each local player
  at the original HUD position. A dead player waits for the team's retry;
  native scene changes carry living partners along using teleport animations.
  Split health pickups refill their collector without freezing the partner;
  Unified keeps the original shared refill pause.

  This release has limited stage coverage. Split may still run below full
  speed, and retries, vehicle stages, and chained scenes need more playtesting.
  Report the release version, stage/area, camera mode, and which player led.

WHERE THINGS LIVE
  saves/     memory cards
  cache/     native code cache, created locally for eligible uncovered code
  mods/      bundled and user-installed mod packages
  input.ini  controller mapping (yours after first launch)

  On Linux the AppImage seeds these into ~/.local/share/MegaManX4Recomp.
  Override that location with MMX4_RECOMP_DATA_DIR.

PRIVACY NOTE
  overlay_captures.json and cache shards produced while playing contain code
  converted from your disc. Do not redistribute your own capture data.

EARLY RELEASE
  The intro, title screen, menus, attract demos, and starting a game are known
  to work. Deep stages and end-to-end memory-card save/load are not yet fully
  verified. Please report an unknown-dispatch halt with where it occurred.
