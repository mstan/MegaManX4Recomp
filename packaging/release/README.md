# Mega Man X4 Recompiled - v1.0.31 Preview

Read START_HERE.txt for setup, controls, co-op and diagnostics. Supply your own original USA SLUS-00561 disc; DISC.md identifies the supported image. OpenBIOS and the native overlay compiler are included.

Adaptive widescreen is enabled for a fresh profile. Existing saved mod and aspect choices remain yours. Use Mods to change presentation or enable X + Zero Co-op. Co-op requires OpenGL; both online players need the same release.

This preview corrects the widescreen camera anchor during horizontal boss-impact shake. See RELEASE_NOTES.md. Native memory-card saves are retained; save states are build-specific.

Windows: extract the complete ZIP and run MegaManX4Recomp.exe. Linux: make the AppImage executable and run it. Keep its writable data folder beside the AppImage. A verified disc image is required on both platforms.

Keyboard defaults: arrows move, X jumps, Z attacks, S dashes, Enter pauses. Controls can be reassigned in the launcher. For local co-op, assign a different input device to each player.

Optional language and Japanese-movie setup is documented in docs/LOCALIZATION.md and docs/FMV_SUBTITLES.md. Upstream movie credits/readmes are preserved in docs/fmv-subtitles. Imported movie data is never bundled.
